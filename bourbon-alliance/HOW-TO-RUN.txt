HOW TO RUN BOURBON ALLIANCE IN DOCKER

1. Open a terminal in this folder (the one containing docker-compose.yml).
2. If an old container exists, run:   docker rm -f bourbon_alliance_web
3. Run:   docker compose up -d --build
4. Open http://localhost:3000

Google sign-in works out of the box. No .env file is required.
To stop:   docker compose down
